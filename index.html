How to test

  1. In the app, add a watch pointing at this page's URL.
  2. Tap ⋮ → Check now once. The first check just records a baseline (no alert) — this is expected.
  3. Edit this page and commit (see below), wait a few seconds for the change to publish, then tap Check now again. The watch should fire.

By mode

  • changed — change any visible text (e.g. the status line above) and re-check.
  • disappears — keyword Anmeldung noch nicht möglich: remove/replace the status line, then re-check. (This mirrors the real Bern site.)
  • appears — keyword Jetzt anmelden: add that phrase to the page, then re-check.

Editing quickly

Open index.html on the gh-pages branch on GitHub, click the pencil, change the status line (for example to Jetzt anmelden), and commit. GitHub Pages republishes within a few seconds.
