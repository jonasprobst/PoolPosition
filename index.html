How to test

  1. Add a watch pointing at this page's URL (or use the seeded one).
  2. Save it — the app fetches a baseline automatically (no alert).
  3. Flip the status line above (closed ⇄ open, see the comment in the HTML source), commit, wait a few seconds for Pages to publish.
  4. In the app tap ⋮ → Check now, then Refresh. The watch should fire.

What each mode keys off

  • changed — any edit to the status line (the visible text hash changes).
  • disappears — the closed-state phrase in the status line goes away when you switch to open.
  • appears — the open-state phrase shows up when you switch from closed to open.

Important: keep the trigger phrases only inside the status line above. If the same words appear elsewhere in this page, a keyword watch will always see them and never fire.
